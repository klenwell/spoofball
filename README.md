# Spoofball

A simple one-player 2D sports simulation for the browser. Draft a team of six discs ("spoofs"), place them on the court, and watch them play a three-round scrum against a computer-managed team.

**Status:** pre-alpha. Nothing playable yet.

## Docs

- [Pitch](docs/pitch.md): the original idea and goals
- [MVP roadmap](docs/roadmap/20261120-mvp-roadmap.md): the plan, epic by epic

Development is tracked in the [Spoofball GitHub Project](https://github.com/klenwell?tab=projects), with one issue and one pull request per step, so the history of how the game was built is public.
